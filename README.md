# Balance book for Android

Official APK downloads for Balance book. This repository contains releases and the app’s update feed only. The source repository is private.

Download the newest APK from [Releases](https://github.com/phooBarred/balance-book-downloads/releases). Install it over your existing copy; do not uninstall or clear app data. Android 8 or newer.

From version 0.3.0 onward, open **Settings → About Balance book → Check for updates** to download and install future releases inside the app. Android asks for installation approval.

New installations start with an empty ledger. Existing installations keep their saved records.
